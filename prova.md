## 📄 Projeto de Teste: Tecnologias da Web - Módulo F - Página de Marketing

Este documento é o projeto de teste para o Módulo F da competição WorldSkills, focado em Tecnologias da Web.

---

### 📰 Introdução

Neste módulo, o objetivo é projetar e criar uma página de marketing para promover a plataforma de jogo P-Media.

* **Título da página:** “A plataforma de jogos da web da próxima geração” 
* **Subtítulo:** “ganha-ganha para desenvolvedores, anunciantes, jogadores” 

#### 🚀 Entregas

1.  Página web para marketing: implementação de uma *one page* para **desktop (1920 pixels de largura)**.
2.  Versão móvel desta página para marketing *one page* (**375 pixels de largura**).

---

### 💻 Descrição do Projeto e Tarefas

Esta página deve causar o maior impacto aos leitores da plataforma de jogos e apresentar a visão do cliente.

* **Tecnologias Permitidas:** Este é o módulo de **HTML e CSS**.
* **Tecnologias Não Permitidas:** Nenhum **PHP e JavaScript** é permitido.

#### Informações Essenciais para a Página Web

A página deve conter as seguintes seções:

1.  **Cabeçalho** 
2.  **Feature** 
3.  **Sobre a empresa - P-Media** 
4.  **Roteiro da plataforma de jogos para 2023** 
5.  **Jogos** 
6.  **Rankings de recordes de todos os usuários** 
7.  **Perfil do usuário** para mostrar as suas pontuações mais altas 
8.  **Versões** 

---

### ✨ Detalhamento das Tarefas por Seção

#### 1. Cabeçalho (Header)

* Deve incluir o **Logo**.
* **Menu de navegação**  com os seguintes itens: Features , Sobre a empresa , Rotero , Jogos , Rankings , Perfil , Versões.
* O Menu deve ser **responsivo**.

#### 2. Features (Slider de Estreia)

* Deve seguir o modelo fornecido nas mídias, atentando aos efeitos de transição e animações.
* O cliente deseja que os **4 principais recursos sejam alternáveis**.
* A alternância deve funcionar **mesmo sem JavaScript**.
* O slider deve conter os seguintes slides : Jogos , Rankings , Perfil do usuário para mostrar as suas pontuações mais altas , Versões.
* Você deve utilizar as imagens de recursos para marketing fornecidas.
* Insira um efeito de transição no slider conforme o vídeo do protótipo disponibilizado.

#### 3. Sobre a empresa

* Deve conter o **logo da empresa** e um **breve texto** sobre.
* Deve ser inserida uma **animação no logo** conforme fornecido no vídeo do protótipo.

#### 4. Área para Roteiro Ecossistêmico para 2023

* O cliente, P-Media Company, gostaria de apresentar o roteiro do ecossistema.
* Criar uma área na *one page* com base no **layout disponibilizado**.
* Deve mostrar a visão e apresentar o futuro brilhante de forma confiante.
* Quaisquer formas de gráficos, incluindo animação, podem ser usadas, desde que representem o relacionamento corretamente.
* **Nota:** Roteiro significa plano futuro. Os recursos mencionados são apenas para mostrar a visão, não para implementação de recursos.

#### 5. Jogos

* A seção jogos deve apresentar os principais jogos da plataforma.
* Devem ser exibidos **4 cards** conforme o layout disponibilizado e as **animações** conforme o vídeo do protótipo.

#### 6. Ranking

* A seção rankings deve exibir uma **tabela** com o ranking dos jogadores[cite: 63, 64].
* As colunas devem ser: Posição , Perfil do jogador , Data , Pontos , Jogo.
* Nas colunas **Data, Pontos e Jogo** deve conter **filtros**.
* A tabela deve conter as **animações** conforme o vídeo do protótipo.

#### 7. Perfil

* A seção perfil deve ser criada conforme o **layout fornecido**.
* O gráfico de barras e o gráfico circular devem ser criados e animados utilizando **HTML e CSS**, conforme mídia e vídeo do protótipo.

#### 8. Versões

* A seção contem um **elemento interativo** para exibir os jogos e suas versões.
* Deve ser aplicado os **efeitos** conforme o vídeo do protótipo fornecido.

---

### ♿ Acessibilidade (WCAG 2.1)

O cliente deseja ter uma boa acessibilidade seguindo as **WCAG 2.1** (Guia de Acessibilidade de Conteúdo Web).

* Serão avaliados:
    * **Botão para alto contraste**.
    * Uso da **tag alt**.
    * O tamanho do texto poderá ser dimensionado para cima ou para baixo de **50% a 200%**.
* Somente o **botão de alto contraste** deve ser **funcional**.
* A posição dos itens de acessibilidade pode ser definida pelo competidor.
