## 📄 Projeto de Teste: Tecnologias da Web - Módulo F - Página de Marketing

Este documento é o projeto de teste para o Módulo F da competição WorldSkills, focado em Tecnologias da Web.

---

### 📰 Introdução

[cite_start]Neste módulo, o objetivo é projetar e criar uma página de marketing para promover a plataforma de jogo P-Media[cite: 13].

* [cite_start]**Título da página:** “A plataforma de jogos da web da próxima geração” [cite: 14]
* [cite_start]**Subtítulo:** “ganha-ganha para desenvolvedores, anunciantes, jogadores” [cite: 14]

#### 🚀 Entregas

1.  [cite_start]Página web para marketing: implementação de uma *one page* para **desktop (1920 pixels de largura)**[cite: 16].
2.  [cite_start]Versão móvel desta página para marketing *one page* (**375 pixels de largura**)[cite: 17].

---

### 💻 Descrição do Projeto e Tarefas

[cite_start]Esta página deve causar o maior impacto aos leitores da plataforma de jogos e apresentar a visão do cliente[cite: 19].

* [cite_start]**Tecnologias Permitidas:** Este é o módulo de **HTML e CSS**[cite: 20].
* [cite_start]**Tecnologias Não Permitidas:** Nenhum **PHP e JavaScript** é permitido[cite: 20].

#### Informações Essenciais para a Página Web

[cite_start]A página deve conter as seguintes seções[cite: 22]:

1.  [cite_start]**Cabeçalho** [cite: 23]
2.  [cite_start]**Feature** [cite: 33]
3.  [cite_start]**Sobre a empresa - P-Media** [cite: 34]

8.  [cite_start]**Versões** [cite: 39]

### ✨ Detalhamento das Tarefas por Seção

#### 1. Cabeçalho (Header)

* [cite_start]Deve incluir o **Logo**[cite: 24].
* [cite_start]**Menu de navegação** [cite: 25] [cite_start]com os seguintes itens: Features [cite: 26][cite_start], Sobre a empresa [cite: 27][cite_start], Rotero [cite: 28][cite_start], Jogos [cite: 29][cite_start], Rankings [cite: 30][cite_start], Perfil [cite: 31][cite_start], Versões[cite: 32].
* [cite_start]O Menu deve ser **responsivo**[cite: 41].

#### 2. Features (Slider de Estreia)

* [cite_start]Deve seguir o modelo fornecido nas mídias, atentando aos efeitos de transição e animações[cite: 43].
* [cite_start]O cliente deseja que os **4 principais recursos sejam alternáveis**[cite: 51].
* [cite_start]A alternância deve funcionar **mesmo sem JavaScript**[cite: 51].
* [cite_start]O slider deve conter os seguintes slides [cite: 45][cite_start]: Jogos [cite: 46][cite_start], Rankings [cite: 47][cite_start], Perfil do usuário para mostrar as suas pontuações mais altas [cite: 48][cite_start], Versões[cite: 49].
* [cite_start]Você deve utilizar as imagens de recursos para marketing fornecidas[cite: 50].
* [cite_start]Insira um efeito de transição no slider conforme o vídeo do protótipo disponibilizado[cite: 52].

#### 3. Sobre a empresa

* [cite_start]Deve conter o **logo da empresa** e um **breve texto** sobre[cite: 54].
* [cite_start]Deve ser inserida uma **animação no logo** conforme fornecido no vídeo do protótipo[cite: 54].

#### 4. Área para Roteiro Ecossistêmico para 2023

* [cite_start]O cliente, P-Media Company, gostaria de apresentar o roteiro do ecossistema[cite: 56].
* [cite_start]Criar uma área na *one page* com base no **layout disponibilizado**[cite: 57].
* [cite_start]Deve mostrar a visão e apresentar o futuro brilhante de forma confiante[cite: 58].
* [cite_start]Quaisquer formas de gráficos, incluindo animação, podem ser usadas, desde que representem o relacionamento corretamente[cite: 59].
* **Nota:** Roteiro significa plano futuro. [cite_start]Os recursos mencionados são apenas para mostrar a visão, não para implementação de recursos[cite: 60].

#### 5. Jogos

* [cite_start]A seção jogos deve apresentar os principais jogos da plataforma[cite: 61].
* [cite_start]Devem ser exibidos **4 cards** conforme o layout disponibilizado e as **animações** conforme o vídeo do protótipo[cite: 62].

#### 6. Ranking

* [cite_start]A seção rankings deve exibir uma **tabela** com o ranking dos jogadores[cite: 63, 64].
* [cite_start]As colunas devem ser: Posição [cite: 65][cite_start], Perfil do jogador [cite: 66][cite_start], Data [cite: 67][cite_start], Pontos [cite: 68][cite_start], Jogo[cite: 69].
* [cite_start]Nas colunas **Data, Pontos e Jogo** deve conter **filtros**[cite: 70].
* [cite_start]A tabela deve conter as **animações** conforme o vídeo do protótipo[cite: 70].

#### 7. Perfil

* [cite_start]A seção perfil deve ser criada conforme o **layout fornecido**[cite: 72].
* [cite_start]O gráfico de barras e o gráfico circular devem ser criados e animados utilizando **HTML e CSS**, conforme mídia e vídeo do protótipo[cite: 72].

#### 8. Versões

* [cite_start]A seção contem um **elemento interativo** para exibir os jogos e suas versões[cite: 74].
* [cite_start]Deve ser aplicado os **efeitos** conforme o vídeo do protótipo fornecido[cite: 74].
