# README

## 🚀 A Próxima Geração de Plataformas de Jogos Web

O **P-Media** é um projeto de *landing page* desenvolvido em **HTML** e **CSS** puro, com o objetivo de promover o lançamento de uma empresa fictícia de jogos e entretenimento web. O projeto demonstra habilidades de desenvolvimento *frontend*, focando em um design moderno, responsivo e com seções bem definidas para apresentar a proposta de valor da empresa.

### ✨ Destaques do Projeto

*   **Design de Landing Page:** Estrutura clássica de *landing page* para conversão e apresentação de produto.
*   **Foco em Web Games:** O conteúdo sugere uma plataforma de jogos web, com foco em um modelo "ganha-ganha-ganha" para desenvolvedores, anunciantes e jogadores.
*   **Seções de Conteúdo:** O projeto inclui seções para:
    *   Banner Principal (Hero Section)
    *   Recursos/Funcionalidades (Features)
    *   Sobre Nós (About Us)
    *   Contato (Contact)
*   **Tecnologias Frontend:** Utilização de HTML para a estrutura e CSS para a estilização completa, sem dependências de frameworks ou bibliotecas JavaScript.

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
| :--- | :--- |
| **HTML5** | Estrutura e marcação semântica do conteúdo. |
| **CSS3** | Estilização completa, incluindo layout flexível (`d-flex`) e efeitos visuais. |

### 📂 Estrutura do Projeto

O projeto segue uma estrutura de arquivos organizada:

```
P-Media/
├── .idea/          # Arquivos de configuração do ambiente de desenvolvimento
├── media/          # Arquivos de mídia, como imagens e vídeos
├── styles/         # Arquivos de estilo CSS (provavelmente styles/style.css)
├── index.html      # Página principal (Landing Page)
├── prova.md        # Arquivo de teste ou rascunho
└── README.md       # Este arquivo
```

### 💡 Conceito Central

A P-Media é apresentada como uma evolução de um estúdio de animação para uma plataforma de entretenimento com **Jogos HTML5**, visando ser a próxima geração de plataformas de jogos web.

### 🚀 Como Visualizar

Para visualizar a *landing page*, basta clonar o repositório e abrir o arquivo `index.html` em seu navegador web:

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/P-Media.git

# 2. Navegue até o diretório do projeto
cd P-Media

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
# (Exemplo para Windows)
start index.html
```
